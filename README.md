
# ASL Sign Language Recognition

A sign language recognition project built using Python and computer vision.

## Features

- Sign language recognition using trained deep learning models
- Model weights for inference
- Python-based implementation

## Project Files

- `asl_integration_final.py` — Main integration script
- `asl_mediapipe_final.py` — MediaPipe-based implementation
- `model_weights/` — Trained model weights
- `asl.jpg` — Project image

## Requirements

Python and the required libraries used by the project, including MediaPipe and PyTorch.

## How to Run

1. Clone this repository.
2. Install the required Python dependencies.
3. Configure the model paths.
4. Run the appropriate Python script.
